# Seventeen Tides — Dezessete Marés

*Dezessete partiram. Uma maré trouxe você de volta.*

Sobreviva ao naufrágio, construa sua jangada e navegue por um arquipélago sem fim atrás do tesouro secreto da sua tripulação.

## ⬇️ [Baixar para Windows](https://github.com/vanngilha/seventeen-tides/releases/latest/download/SeventeenTides-Setup.exe)

Windows 10/11 64-bit · acesso antecipado · grátis.

- **Atualiza sozinho:** depois de instalado, o jogo avisa quando sai versão nova e baixa só o que mudou.
- **Aviso do Windows:** jogos independentes ainda sem certificado mostram "app desconhecido". Clique em *Mais informações* → *Executar assim mesmo*.
- **Jogar no navegador (prévia):** https://ilha-tesouro.vercel.app/jogar

Este repositório guarda apenas os instaladores (veja em *Releases*). O código do jogo não fica aqui.
